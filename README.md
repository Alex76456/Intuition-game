# Great Intuition: многопользовательская игра на интуицию

## Проект доступен по ссылке

https://intuitiongame.onrender.com/

---

## Требования

- Node.js 16+
- npm или yarn

## Как запустить локально

- `npm install` или `yarn`
- `npm run dev` или `yarn dev` — режим разработки
- для production: `npm run build` → `npm start` (или `yarn build` → `yarn start`)

## Функционал приложения

### Игровой процесс

- **Суть игры:** сервер загадывает число от 0 до 100, игроки вводят своё число; побеждает тот, чьё число ближе к загаданному.
- **Раунды:** длительность раунда 60 секунд, по окончании объявляются загаданное число и победитель.
- **Реальное время:** синхронизация состояния через Socket.io (ожидание, идёт раунд, результат).
- **Боты:** поддерживаются бот-игроки на сервере.
- **Один ход на раунд:** в каждом раунде можно отправить только одно число.

### Интерфейс и настройки

- **Смена темы (светлая / тёмная):** переключатель в шапке (иконка солнца/луны). Выбор сохраняется в `localStorage` (`gi-theme`).
- **Смена языка (RU / EN):** кнопки RU и EN в шапке. Интерфейс переводится через хук `useTranslation` и словарь `src/locales/en.ts`. Выбор сохраняется в `localStorage` (`gi-locale`).

### Пользователь и связь

- **Никнейм:** при первом заходе показывается модальное окно ввода ника (3–20 символов, буквы, цифры, пробел, `_`, `-`). Ник можно изменить; хранится в `localStorage`.
- **Статус соединения:** отображается индикатор подключения к серверу и кнопка «Переподключиться» при потере связи.

### Статистика и рейтинги

- **Личная статистика:** победы, средняя точность, сыграно игр, попыток, серия побед, лучший результат (минимальная разница).
- **Таблицы лидеров (Firebase):** по точности, по победам, по количеству игр, по количеству предложений.

### Остальное

- **Правила:** блок с кратким описанием правил игры.
- **Чат:** обмен сообщениями в реальном времени; серверные уведомления (приветствие, загаданное число, результаты).
- **Таймер и участники:** отображение оставшегося времени раунда и списка участников текущего раунда.

## Технологии

- **Next.js** — фреймворк
- **React 18**, **TypeScript**
- **Redux Toolkit** — глобальное состояние (синк состояния, чат, статистика, ник)
- **Socket.io** (client + server) — реальное время
- **Firebase** — таблицы лидеров и статистика
- **React-JSS** — стили с темизацией (светлая/тёмная тема)
- **Context API** — `ThemeContext`, `LocaleContext`
- **clsx** — условные классы

## Планы по доработке

### Архитектура и код

- **Разделение общего состояния** — сейчас один `commonSlice` смешивает чат, статистику, ник, раунд. Имеет смысл разнести по доменам: `userSlice` (ник, nickConfirmed), `gameSlice` (раунд, таймер, lastResult), `chatSlice` (сообщения), `statisticSlice` или оставить статистику в game. Упростит тесты и изменения.
- **Хук/контекст для Socket.io** — инициализация и все подписки сейчас в `pages/index.tsx`. Вынести в `useSocket()` или `SocketProvider`: подключение, подписки на события, реконнект. Страница станет тоньше, логику сокета можно тестировать отдельно.
- **Разбить common-файлы** — constants, utils, redux по подкатегориям (game, chat, user, leaderboard) для ясной навигации по коду.

### Безопасность и конфигурация

- **Секреты и env** — конфиг Firebase сейчас в коде (`db/firebase.ts`). Вынести в переменные окружения (`NEXT_PUBLIC_*` для клиента, серверные — для API), не коммитить ключи, описать в README или `.env.example`.

### Качество и надёжность

- **Тестирование** — тестов нет. Добавить: unit-тесты (Vitest/Jest) для utils, редьюсеров, хуков; при необходимости e2e (Playwright/Cypress) для входа в игру и одного раунда.
- **Обработка ошибок** — Error Boundary для падений React; явная обработка ошибок Socket (переподключение уже есть) и Firebase (лидерборд, статистика); при желании — логирование в Sentry или аналог.

### Пользовательский опыт и доступность

- **Доступность (a11y)** — фокус-ловушка и закрытие по Escape в модалке ника; объявление смены статуса раунда/таймера для скринридеров (`aria-live`); проверка контраста тем.
- **Адаптив и мобильная версия** — частично есть (breakpoint 1200px). При необходимости — донастроить тач, размеры кнопок и полей ввода для маленьких экранов.

### Инфраструктура и стек

- **Обновление Next.js** — проект на Next 12; запланировать переход на 14/15 (LTS), при желании — эксперименты с App Router.

### Игровой функционал (идеи)

- **История раундов** — показ последних N результатов (загаданное число, победитель) для контекста без прокрутки чата.
- **Настраиваемые параметры** — длительность раунда или диапазон числа (например 0–1000) в настройках комнаты/сервера, если появится концепция комнат.
